# GT6 坩埚体系完整复刻实施规划

## 1. 文档目的

本文档用于指导 `GT6Addition` 将现有坩埚相关代码替换为一套按 GT6 语义运行的单方块坩埚体系，包括：

- 单方块熔炼炉（GT6 `Smeltery`）
- 坩埚浇筑口
- 熔融材料十字分流管
- 5×5 可雕刻模具
- 固定方块铸造盆
- 洗浴盆与搅拌碗终端
- 铸币模具及相关工具交互
- HU、CU、KU、Vis Ignis 对温度与内容物的作用
- 熔化、凝固、合金化、沸腾、燃烧、爆炸、酸腐蚀与熔毁

本次工作采用替换式重构，不为现有存档、旧 NBT、旧自动化接口或 CEu 固化机配方提供兼容层。

## 3. 复刻原则

### 3.1 必须一致的内容

- 材料单位、容量、温度、重量和能量换算。
- 每 tick 的执行顺序。
- 材料熔化与凝固时的目标材料转换。
- 合金候选选择和单 tick 合金化次数。
- 危险判定顺序与触发温度。
- 坩埚、龙头、分流管和模具之间的拉取式调用关系。
- 模具的 5×5 雕刻、图案识别、冷却和出件。
- 工具、红石和自动拉取模式。

### 3.2 明确不保留的现有行为

- 不再把坩埚当作普通 Forge 流体罐供管道任意抽取。
- 不再通过 `RecipeMaps.FLUID_SOLIDFICATION_RECIPES` 驱动冷却模具。
- 不再以 `molten` 布尔值作为材料相态的权威来源。
- 不再按机器 tier 限制每 tick HU 输入。
- 不再使用“注册材料组分自动推导全部合金”的近似逻辑。
- 不再保留当前龙头的通用流体能力回退路径。
- 不为旧 `CoolingMold`、`CastingBasin` 或坩埚 NBT 做迁移。

### 3.3 本项目保留的本地交互约定

方块选择/命中范围继续使用完整方块，满足当前项目“整格可点击”的要求；但顶部、侧面、底部的功能权限仍严格按 GT6 判定。完整命中范围不代表所有面都能执行同一种操作。

## 4. 目标系统总览

```text
HU / Vis Ignis ─┐
CU ─────────────┼─→ 单方块熔炼炉（GT6 `Smeltery`）
KU + 氧气 ──────┘              │
                               │ ITileEntityCrucible 风格拉取协议
                 ┌─────────────┴─────────────┐
                 ▼                           ▼
             坩埚浇筑口                   坩埚浇筑道
                 │                           │
                 └─────────────┬─────────────┘
                               ▼
             5×5 雕刻模具 / 方块铸造盆 / 洗浴盆 / 搅拌碗
                               │
                               ▼
                        冷却、凝固、取件
```

系统采用“目标主动拉取”模型：坩埚不主动向外推送材料。模具、龙头或下游设备发起请求，沿专用网络找到坩埚，再由坩埚扣除实际被接收的材料量。

## 7. 核心接口

### 7.1 坩埚来源接口

接口只表达 GT6 专用材料传输，不暴露普通流体罐语义。

```java
public interface IGt6Crucible {
    boolean fillMoldAtSide(IGt6Mold mold,
                           @Nullable EnumFacing sideOfCrucible,
                           @Nullable EnumFacing sideOfMold);
}
```

返回值沿用 GT6 的成功/失败语义。实际扣除量由模具 `fillMold` 的返回值决定。

### 7.2 模具接口

```java
public interface IGt6Mold {
    boolean isMoldInputSide(@Nullable EnumFacing side);
    long getMoldMaxTemperature();
    long getMoldRequiredMaterialUnits();
    long fillMold(CrucibleMaterialStack material,
                  long temperature,
                  @Nullable EnumFacing side);
}
```

与当前接口相比：

- 移除 `simulate`。
- 移除按指定材料查询容量的参数。
- 允许调用方传入比需求更多的材料，并由返回值表示实际扣除量。
- 模具必须进行输入面、酸性、温度、产物存在性和空闲状态检查。

### 7.3 材料堆

```java
public final class CrucibleMaterialStack {
    Material material;
    long amount;
}
```

不保存 `molten` 字段。相态由当前温度与材料熔点实时决定。跨越熔点时，材料本身转换为 `targetSmelting` 或 `targetSolidifying`。

## 8. 材料数据层

GTCE 的 `Material` 不能完整表达 GT6 坩埚需要的全部数据，因此必须建立独立数据层，不能继续用猜测和默认值替代。

每种可进入坩埚的材料至少需要：

- 熔点 K
- 沸点 K
- 单位重量或等价热质量
- 密度，用于选择液面最上层材料
- `targetSmelting` 及数量换算比例
- `targetSolidifying` 及数量换算比例
- 是否允许熔化
- 是否酸性
- 是否可燃
- 是否不可燃
- 是否爆炸
- 液体映射及单位换算
- 合金候选反向索引

建议先将 GT6 材料定义导出为本项目的数据表，再将 GT6 名称映射到 GTCE `Material`。无法一一对应的材料不得静默近似：要么在注册阶段报错，要么明确从坩埚输入白名单排除。

`GTValues.M` 作为本项目的一个完整材料单位 `U`。所有内部计算使用材料单位，只有容器交互和显示时转换为 mB/L。

## 9. 单方块熔炼炉的精确逻辑

### 9.1 固定常量

- 容量：`16 × U`
- 外壳基础热质量：外壳材质 `7 × U` 对应重量
- 能量换算基数：每 100 kg 每升高 1 K 消耗 1 HU
- 环境冷却等待：100 tick
- 环境温度修正周期：10 tick
- 过热预警：距离耐温上限 100 K
- 热拆除阈值：1300 K
- 气体伤害和火焰范围按 GT6 单方块熔炉常量复刻

### 9.2 每 tick 顺序

必须保持以下顺序，不能为了代码方便任意调换：

1. 读取环境温度和本 tick 开始时的内容哈希。
2. 处理雨水加入。
3. 顶部吸取掉落物到唯一输入槽。
4. 解析并处理输入槽中的一个物品。
5. 搜索一次最佳合金配方并执行一次。
6. 清理空材料、低于空气密度的内容和非法材料。
7. 处理沸腾、燃烧、爆炸和酸腐蚀。
8. 仅在温度跨越熔点或内容刚变化时执行熔化/凝固目标转换。
9. 计算总重量、总量、最轻材料和客户端液面。
10. 将热量池一次性换算成整数温度变化。
11. 若发生温度变化，将环境冷却等待重置为 100 tick。
12. 无能量变化且等待结束后，每 10 tick 向环境温度移动 1 K。
13. 应用 GT6 的最低温度钳制。
14. 检查外壳熔毁。
15. 更新 100 K 过热预警状态。

能量换算公式：

```text
总重量 = 外壳热质量重量 + 所有内容物重量
每 K 能耗 = 1 + floor(总重量 / 100 kg)
温度变化 = 热量池 / 每 K 能耗
热量池 -= 温度变化 × 每 K 能耗
当前温度 += 温度变化
```

热量池允许为负。CU 注入负热量，因此相同公式同时负责升温和降温。

### 9.3 输入解析

`CrucibleInputResolver` 必须支持：

- 普通矿辞物品的所有材料组成，而非只取一个主材料。
- `oreRaw`、`blockRaw`、`crateGtRaw`、`crateGt64Raw`。
- 标准矿石和致密矿石倍率。
- 无材料数据物品进入后直接销毁并播放熄灭声。
- 添加前进行完整容量检查；整批内容不能容纳时不得部分加入。
- 新材料按旧内容物重量、外壳热质量和输入温度进行加权混温。

### 9.4 熔化与凝固

- 当前温度首次达到材料熔点时，将其按比例替换为 `targetSmelting`。
- 当前温度首次跌破材料熔点时，将其按比例替换为 `targetSolidifying`。
- 新内容加入时也必须重新检查转换，即使温度本 tick 没有跨界。
- 同材质堆必须合并，零数量堆必须删除。
- 不使用单独的熔融布尔值。

### 9.5 合金化

- 候选只来自当前材料引用的 GT6 合金创建配方。
- 坩埚温度必须达到目标合金熔点。
- 所有组分必须足量。
- 组分中最多允许一个未达到自身熔点。
- 计算每个配方可执行次数。
- 选择 `可执行次数 × commonDivider` 最大的候选。
- 每 tick 最多执行一个候选，不进行当前实现的 64 次循环链式合成。
- 扣除组分后加入目标合金材料堆。

### 9.6 危险顺序

危险处理按以下优先顺序：

1. 空、非法或空气材料清理。
2. 密度不高于空气的材料逸散。
3. 达到沸点，或可燃且高于约 313 K 的非熔炼材料，发生烧失/沸腾。
4. 沸腾材料按沸点对周围实体造成温度伤害。
5. 高沸点材料在周围生成火焰。
6. 若该材料同时具有爆炸属性，清空全部内容并按材料占容量比例爆炸。
7. 非耐酸外壳遇到酸性材料，清空并将机器移除。
8. 最后处理熔化和凝固转换。

这意味着爆炸不是“达到熔点立即爆炸”，而是在材料进入沸腾/燃烧分支后触发。

### 9.7 熔毁和拆除

- 外壳耐温：`外壳材质熔点 × 1.10`。
- 超温后清空内容、造成高温伤害、生成火焰并把方块变成流动岩浆。
- 非创造玩家在温度不低于 1300 K 时拆除，机器不掉落并变成岩浆。
- 距离上限 100 K 时启用红热/发光警告渲染。

## 10. 能源语义

坩埚体系改为注入式能量缓冲，不再每 tick 主动读取正下方设备。

| 能量 | GT6 行为 |
|---|---|
| HU | 向热量池增加绝对值 |
| Vis Ignis | 与 HU 一样增加热量池 |
| CU | 从热量池减去绝对值，可产生负温度变化 |
| KU | 不改变温度；有氧时按输入量向坩埚加入空气材料，用于炼钢 |

单方块熔炼炉接受 GT6 对应有效面的上述能源；不得套用 tier 电压或 `2 × V[tier]` 限流。

必须修复自定义 HU/CU 能力“读取但不扣除源能量”的问题。注入方法返回实际接受包数，源设备只按返回值扣除。

## 11. 专用材料传输网络

### 12.1 传输原则

- 不使用 Forge `IFluidHandler` 代表坩埚输出。
- 网络不保存材料，不进行被动扩散。
- 每次请求从目标向源递归查找。
- 坩埚只在目标确认接收量后扣除材料。
- 只允许当前温度不低于熔点、且材料已处于自身 `targetSmelting` 形态的内容输出。

### 12.2 龙头

龙头按 GT6 重写：

- 朝向面连接坩埚或分流网络。
- 右键执行一次拉取。
- 默认红石模式：收到相应方块更新并有红石输入时拉取。
- 猴扳手切换自动模式；自动模式每 20 tick 尝试一次。
- 软锤恢复红石模式。
- 向下搜索目标，可穿过空气和其他龙头。
- 第一个有效目标可以是模具、洗浴盆或搅拌碗。
- 对模具调用 `fillMold`。
- 对洗浴盆/搅拌碗最多灌入一个 `U` 对应流体量。
- 外壳耐温：龙头材质熔点 `× 1.25`。
- 超温变成岩浆。
- 非耐酸龙头拒绝酸性材料。

删除当前龙头的 `transferFluidDownOnce` 和普通流体源/目标回退。

### 12.3 十字分流管

新增 `MetaTileEntityCrucibleCrossing`：

- 自身实现 `IGt6Crucible`。
- 收到一侧请求时，依次向其余三个水平方向转发。
- 任意一个来源成功即返回成功。
- 使用全局请求 ID 和每实例锁 ID 防止环形网络无限递归。
- 每 tick 重置实例锁。
- 上下方向红石输入可转换为水平方向弱红石输出，复刻 GT6 状态指示行为。
- 不具备流体能力、材料缓存或 GUI。

## 13. 5×5 可雕刻模具

### 13.1 状态

- `int shapeBits`：低 25 位对应 5×5 图案。
- `CrucibleMaterialStack content`：当前冷却中的材料。
- `long temperature`：模具与内容温度。
- 单格输出物品。
- `byte autoPullDirections`：四个水平方向开关。
- `boolean useRedstone`：自动拉取是否受红石门控。
- 外壳材质和耐酸属性。

### 13.2 雕刻

- 仅在没有内容和输出物品时允许雕刻。
- 凿子点击顶面中心 12×12 像素区域。
- 将点击坐标映射到 5×5 单元并永久置位。
- GT6 原逻辑不通过再次点击清除单元。
- 扳手、螺丝刀或旋转工具旋转图案。
- 图案匹配注册表后得到指定 `OrePrefix`。
- 非零但未识别的图案按每个已雕刻单元 `U/9` 计算粒模容量。
- 空图案不接受材料。

### 13.3 图案注册表

必须从 GT6 `MultiTileEntityMold.MOLD_RECIPES` 完整移植原始二进制图案及旋转/镜像展开逻辑。目标前缀至少包括：

- `ingot`、`nugget`、`plate`、`plateTiny`
- `ring`、`bolt`、`stick`、`stickLong`
- `gearGt`、`gearGtSmall`
- `casingSmall`、`billet`、`chunkGt`
- 锤、锉、锯、凿子、斧、镐、铲、锄、剑、螺丝刀等工具头
- Builder Wand 工具头

不得用 CEu 流体固化配方替代图案注册表。

### 13.4 接料与冷却

- 仅顶部和水平方向为有效输入面。
- 必须空内容、空输出、有效图案且一次拥有足够材料。
- 非耐酸模具拒绝酸性材料。
- 必须能为 `targetSolidifying` 材料生成目标前缀物品。
- 模具保存注入时温度。
- 每 tick 最多向环境温度移动 5 K。
- 温度超过内容沸点或模具耐温，模具与内容销毁并变岩浆。
- 低于熔点后执行 `targetSolidifying`。
- 若目标材料具有 `COOL2CRYSTAL`，板类输出替换为宝石板前缀。
- 冷却完成后生成输出物品并清空内容量。

### 13.5 自动拉取

- 猴扳手点击顶面边区切换对应水平拉取方向。
- 猴扳手点击中心切换红石门控。
- 软锤关闭全部方向并关闭红石模式。
- 空模具在库存变化、周期检查或红石更新时尝试从选定方向拉取。
- 顶面右键可按点击方向手动请求相邻坩埚/分流网络。
- 钳子无接触伤害取出；空手取出会受到温度伤害。

## 14. 固定方块铸造盆

`MetaTileEntityCastingBasin` 改为 `MetaTileEntityMold` 的固定变体：

- 图案固定为 `blockSolid`。
- 只从顶部接料。
- 需求量固定为一个实心方块前缀的材料量。
- 不支持雕刻、旋转、自动方向或红石配置。
- 冷却、温度、耐酸、熔毁和取件全部复用通用模具逻辑。
- 删除当前按“方块、锭、粉、粒”逐级选择输出的 `createCastResult`。
- 删除普通流体罐输入/输出能力。

## 15. 洗浴盆与搅拌碗

这两类设备作为龙头的特殊终端，不实现通用模具成型：

- 龙头向其输入最多一个材料单位的可映射熔融流体。
- 洗浴盆执行 GT6 Bath 配方，负责浸泡、包覆和流体参与的手工加工。
- 搅拌碗执行 GT6 Mixing Bowl 配方，负责人工混合。
- 保留容器交互、输入/输出槽、雨水和流体温度/密度限制。
- 木质和台式变体在核心逻辑稳定后再注册，但行为必须来自同一核心类。

如果本项目暂时没有完整 Bath/Mixing Bowl 配方数据，设备类和龙头终端协议仍必须先按 GT6 定义，禁止用任意流体罐代替。

## 16. 铸币模具

铸币模具属于铸造后的二次加工，不直接实现 `IGt6Mold`：

- 输入 `plateTiny`。
- 使用锤消耗 2000 工具耐久/使用量，将小板压成硬币。
- 支持手动放入和取出。
- 保留 GT6 当前状态：自定义双面 16×16 币面选择尚未工作，不额外发明行为。

## 18. NBT 与网络同步

### 18.1 熔炼炉

持久化：

- 热量池
- 当前温度
- 上 tick 温度
- 材料堆列表：材料 ID/名称和数量
- 过热状态可重算，不要求持久化

客户端仅同步：

- 液面高度
- 最轻材料显示 ID
- 是否显示熔融纹理
- 过热预警

### 18.2 模具

持久化：

- 25 位图案
- 内容材料和数量
- 温度
- 输出槽
- 自动拉取方向
- 红石模式

客户端同步图案、显示材料、凝固状态和外壳颜色。

### 18.3 不兼容策略

读取旧格式时直接按空机器初始化，不进行字段猜测。开发版本首次进入旧测试世界前应明确提示备份。

## 19. 渲染与命中

- 熔炼炉液面显示密度最低的材料。
- 只有该材料当前达到熔点时使用熔融纹理，否则隐藏液体纹理或使用固态显示。
- 模具显示 5×5 雕刻结果、熔融内容和冷却后的成品状态。
- 距离外壳耐温上限 100 K 时外壳红热并发光。
- 选择框使用完整方块；物理碰撞仍可按模型拆分，二者如受底层 API 限制，则优先保证完整方块可交互。

## 20. JEI/信息展示

- 熔化页由 `CrucibleMaterialRegistry` 生成，展示输入材料、目标熔化材料和熔点。
- 合金页由 `CrucibleAlloyRegistry` 生成，展示精确比例、目标合金和所需温度。
- 模具页展示 5×5 图案、所需材料单位和输出前缀。
- 不把 JEI 页面当作运行配方源；运行逻辑只读取正式注册表。
- 顶部探针信息显示温度、外壳上限、总容量和按密度排序的内容物。

## 24. 最终验收标准

只有同时满足以下条件，才能称为“整套流程按 GT6 实现”：

1. 单方块熔炼炉使用 GT6 对应的材料/热力核心。
2. 内部不再依赖 `molten` 布尔状态决定相态。
3. 热量按重量换算，CU 可通过负热量池降温。
4. 合金来自精确注册表，并且每 tick 只执行一个最佳候选。
5. 危险顺序与 GT6 一致，爆炸不在熔点阶段提前触发。
6. 坩埚输出不暴露为普通流体管道接口。
7. 龙头、分流管和模具使用拉取式材料协议。
8. 模具由 5×5 雕刻图案决定输出，不读取 CEu 固化机配方。
9. 龙头自动/红石、模具方向/红石及全部工具交互可用。
10. 所有关键公式和边界均有自动化测试。
11. JEI、提示文本和渲染展示来自同一正式数据源。

# GT6 Addition

`GT6 Addition` 是一个基于 `Minecraft 1.12.2` 的开发中模组，目标是在 `GregTech / GTQT` 环境下补充一批偏 `GregTech 6` 风格的机器、能量体系与交互逻辑。

项目目前更偏向“实验性移植 + 本地扩展”，主要关注以下两件事：

1. 把部分 `GT6` 风格机器、材质和交互搬到当前模组环境中。
2. 在现有代码基础上整理和扩展 `HU / RU / KU / LU` 等自定义能量体系。

## 项目定位

这个项目是对 `GT6` 的部分复刻。

核心方向包括：

- 引入 `GT6` 风格的单方块机器、工具类方块和小型功能方块。
- 为机器补充独立材质、贴图、方块模型和自定义渲染。
- 扩展多种非标准能量体系，并在机器之间建立转换关系。
- 对现有机器逻辑、效率计算、朝向、交互与配方处理做持续修正。

## 当前主要内容

项目目前已经包含或正在维护以下几类内容：

- `HU` 相关机器：
  简易燃烧室、液体燃烧室、坩埚、浇铸盆、冷却模具、温度传感器等。
- `RU / KU` 相关机器：
  蒸汽轮机、电动机、柴油引擎、RU-KU 引擎、动能蒸汽机、齿轮箱、转轴、旋转泵等。
- `EU / LU` 相关机器：
  自动点火器、电力发电机、CO2 激光器、激光焊接器、激光刻蚀机等。
- 工具与功能方块：
  GT6 风格漏斗、队列漏斗、钵体、微型传送门等。
- 配方与系统扩展：
  自定义配方表、激光焊接配方、对 CEu 原有配方的兼容执行、多能量机器配方处理等。

## 自定义能量体系

本项目围绕多套能量类型工作，目前代码中已经接入或正在使用的体系包括：

- `HU`
  热能方向的机器与高温处理逻辑。
- `RU`
  偏旋转/动力输出方向的能量体系。
- `KU`
  动能机械网络相关机器。
- `LU`
  激光能量体系，用于焊接、刻蚀等机器。
- `EU`
  作为部分机器输入或转换来源，与自定义体系联动。
